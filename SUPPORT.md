## Contact

**SimpleX:** <https://smp14.simplex.im/a#3gZ-zeHs4QrFZKLAN0o3SC_XQJXhj1eYBVTO_c0FAtg>
(open the link with the SimpleX app).

Use it for questions, for reporting a security problem, and for anything you would rather not
post publicly. Please do not put details of a security problem in a public issue.

When you write, say which version you run (`astral-lens` in `backend/pyproject.toml`), your
compute profile, and what the app's own capability panel (Settings) reported; leave out case
data, evidence, names and keys. Astral Lens never needs them to diagnose a problem, and this
project does not want them.
